请选择一台已在Windows蓝牙中配对的iPhone

Android Auto 使用开发者模式连接：在手机开启“head unit server”，下一步填写手机地址。

手机打开荣耀车联或百度CarLife，并确保与电脑在同一网络；电脑会自动发现（UDP 7999），也可填写手机 IP。

测试中：无线 CarLife+ 需要手机先与“车机”完成系统蓝牙配对；未配对时引擎只输出欢迎页并会在数秒后结束，电脑接入蓝牙适配器后即可完整使用。

在手机 Android Auto 开发者选项启动“head unit server”，手机与电脑需在同一网络；也可执行 adb forward tcp:5277 tcp:5277 后填写 127.0.0.1。

留空则监听 UDP 7999 自动发现；手机需与电脑在同一 Wi-Fi 或热点下。
